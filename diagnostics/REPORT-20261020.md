### 11.2 진단 도구 보완 (`78a69e2`)

1차 상태는 다음과 같았습니다.
- `diag_common.py`가 `assert URL.startswith(("http://127.0.0.1:8086", "http://frontend"))`로 주소를 검사했습니다.
  - 문자열 접두어 비교라서 `http://127.0.0.1:8086.example`이나 `http://127.0.0.1:80861` 같은 주소를 거르지 못합니다.
  - `assert`는 최적화 실행(`-O`)에서 사라집니다.

- Python 요청은 환경 프록시를 쓰고 리다이렉트를 그대로 따랐습니다.

보완한 내용 (`scripts/diag_scope.py` 한 곳):
- `DIAG_URL`은 `http://127.0.0.1:8086`, `NU_URL`은 `http://127.0.0.1:8888`(또는 `off`)만 허용합니다.
  - scheme·hostname·port를 정확히 비교합니다.
  - 사용자 정보·경로·쿼리·조각이 있으면 거절합니다.
  - 거절은 `ScopeError`로 합니다.
- Python 요청은 프록시를 쓰지 않고, 리다이렉트는 이어지는 주소가 범위 안일 때만 따릅니다.

  - **발견:** Playwright가 덧붙이는 `<-loopback>`에 맡기고 `127.0.0.1:8086`만 예외로 두면, 허용 주소까지 프록시로 가서 막혔습니다. `<-loopback>`을 맨 앞에 두어야 허용 주소만 직접 연결됩니다(Edge 155에서 루프백 임시 서버로 확인).
- 운영 health 감시(`monitor.py`·`health_timing.py`)는 별도 경로입니다.
  - 고정 주소 하나에 GET만 보냅니다.
  - 프록시를 쓰지 않고 리다이렉트를 따르지 않습니다.
  - 진단 모듈을 가져오지 않습니다.
  - 진단용 쓰기 요청(시드·업로드)은 운영 주소로 보낼 수 없습니다.

- `contrast_check.py`는 소수 둘째 자리에서 **반올림**한 값을 기록했습니다(예: 2.996이 3.00으로 보일 수 있음). 원시값(`ratio_raw`)과 내린 값을 함께 남기도록 바꿨습니다.

다시 계산한 결과 (`round3/contrast-calc.txt`, `round3/contrast-recalc-round1.txt`):

| 대상 | 개수 | 원시값 변화 | 판정 변화 |
|---|---|---|---|
| 1차 계산 색 조합 (`contrast_calc.py`) | 14 | 모두 0 | 0 |
| 1차 `contrast_check` 기록 (전경·배경 색으로 재계산) | 34 | 모두 0 (경계 차이) | 0 (반올림 기록값 → 원시값으로 바꿔도 같음) |

- 8비트 정수 색(0~255)에는 두 경계값 사이(채널 값 약 10.02~10.31)에 들어가는 값이 없습니다. 이번 합성 색에도 그 범위의 채널이 없었습니다.
- `contrast_check.py`는 계산식만 바꿨고, 화면에서 다시 실행하지는 않았습니다(미검증). 3차의 화면 대비 측정은 `a11y_fix_check.py`(같은 `contrast_calc` 계산)로 했습니다.

### 12.8 3차 시험 도구 오류 (제품 결함 아님)

- **관리자 검증 실행:** 버튼을 패널 제목 '검사 시작'으로 찾아 검증이 실행되지 않았습니다. 실제 버튼 글자는 '검증 실행 (N개 파일)'입니다. 고쳐서 `.mapping-pick select`를 띄워 쟀습니다.
- **묶기 요약 입력:** `.bd-input`·`.bd-choice select`는 단위·기간을 확인할 수 없거나 단위가 다른 파일이 있을 때만 나옵니다. 첫 측정에는 없었고, 그런 합성 파일 두 개를 만들어 다시 쟀습니다.
- **입력 규칙 기록:** 처음에는 요소마다 규칙 하나만 기록해 `.wk-home select·textarea`가 '미측정'으로 나왔습니다. 적용되는 규칙을 모두 기록하게 고쳤습니다.
- **외곽선 대비:** 배경 전환(0.15초) 도중에 계산된 색을 읽었습니다. 0.4초 기다린 뒤 다시 쟀습니다.
  - 2차 기록의 '라디오 원 링 투명'도 같은 이유로 보입니다(확정 아님). 이번 측정에서는 20% 투명 링(대비 약 1.3)이 있고, 초점 표시는 카드 외곽선이 맡습니다.
- **업로드 중 확인 순서:** 영역 글자를 클릭한 뒤라 완료 뒤 초점이 본문으로 빠진 것처럼 기록됐습니다. 클릭을 먼저, 버튼 Enter를 나중에 하도록 바꿔 다시 쟀습니다.
