# 메일 통계 표준 항목 · 산식 · 조직 식별

메일 사용량 자료(발신·수신 건수, 용량, 조회, 메일함)를 취합할 때 쓰는 표준 항목의 정의입니다. 어느 항목을 같은 뜻으로 보고, 어느 항목을 서로 더하면 안 되는지 정리했습니다.

- 정의의 원본: `backend/app/standard_dictionary.json`(이름·설명·별칭), `backend/app/mail_fields.py`(계산 범위), `backend/app/formulas.py`(합계 산식)
- 도입: PR #21(항목·별칭·단위 보호), 이 문서와 산식 확인(D-01)·조직 식별 보완(D-02)
- 과거 매핑·결과는 새 정의로 일괄 변경하지 않습니다. 새 업로드·새 확정·새 계산부터 적용됩니다.

## 1. 항목 정의

공통 규칙:
- **발생량**은 기간 안의 건수·용량이라 같은 기간 안에서 더할 수 있습니다.
- **시점값**은 기준일 현재 보유량이라 기준일이 다른 값끼리 더하지 않습니다(분석이 막음).
- **자료형:** 숫자 칸, 또는 숫자로 읽을 수 있는 글자(사용자가 수량 항목으로 확정한 열)만 계산합니다. 빈칸·비공개 표기('-', 'x', '…')·글자는 0으로 바꾸지 않고 사유와 함께 뺍니다.
  - 음수·소수 건수를 따로 막지는 않습니다 (남은 제한).
- **단위:** 건수(건)와 용량(MB)은 서로 다른 항목이라 함께 더하지 않습니다.
  - GB·MiB나 단위 없는 용량 열은 MB 항목에 자동으로 연결하지 않습니다.
  - 사용자가 확정했더라도 분석에서 단위를 따로 확인하며, 자동 환산은 없습니다.

| 항목 key | 표시 이름 | 단위 | 성격 | 산식 (합계 = 구성 항목의 합) | 별칭 (자동 연결되는 다른 이름) |
|---|---|---|---|---|---|
| `mail_sent_count` | 발신Mail건수 | 건 | 발생량 | — | 발신 Mail 건수, 발신메일건수 |
| `mail_external_sent_count` | 발신외부건수 | 건 | 발생량 | — | 발신 외부 건수, 외부발신건수 |
| `mail_sent_total_count` | 발신건수합계 | 건 | 발생량 | 발신Mail건수 + 발신외부건수 | 총 발신 건수, 발신 건수 합계 |
| `mail_system_sent_count` | 시스템발신수 | 건 | 발생량 | — | 시스템 발신수, 시스템발신건수 |

| 항목 key | 표시 이름 | 쓰임 | 별칭 |
|---|---|---|---|

뜻이 다른 열은 이름이 비슷해도 자동으로 합치지 않습니다.
- 여러 건수 열(발신·수신·외부·조회 등)은 일반 '건수'(`count`)로 몰지 않고 위 항목으로 따로 연결합니다.
- 사용자 확정이 언제나 먼저입니다(파일별 확정). 그다음이 사전, 학습 별칭 순입니다.

## 2. 합계 산식 확인 (`app/formulas.py`)

같은 이름의 합계라도 자료마다 산식이 다를 수 있습니다. 그래서 이름만 믿지 않고 값으로 확인합니다.

- **확인 조건:** 합계 열과 그 구성 항목 열이 같은 시트에 모두 연결돼 있을 때만 비교합니다.
  - 숫자로 읽을 수 없는 칸이 있는 행은 비교하지 않습니다(0으로 보지 않음). 비교한 행 수와 비교하지 못한 행 수를 함께 적습니다.
  - 정수는 정확히 비교합니다.
- **차이가 있을 때:** 같은 시트의 열로 만든 다른 산식이 맞는지 함께 봅니다. 예: '발신건수합계'가 Mail+외부와는 다르고 Mail+외부+시스템+대용량과 맞는 경우.
- **확정한 값을 고치거나 산식을 대신 고르지 않습니다.** 결과는 세 가지로 나눕니다 (2026-10-23 정책).

| 상태 | 뜻 | 통합표·파일별 시트 (원본 값을 옮김) | 데이터 통계 분석·묶기 통계 요약 (같은 뜻으로 더함) |
|---|---|---|---|
| 산식 확인 | 비교한 행이 모두 산식과 같음 | 알림 없음 | 대상·요약 시트에 "산식 확인 — 비교한 n행 모두 같음 (비교하지 않은 행 k)" |
| 산식 불일치 | 비교한 행 중 산식과 다른 행이 있음 | **경고** (통합 전 검사 `formula_mismatch`, 묶기 계획의 경고) — 원본 값 그대로 넣음 | **막음** — 그 시트를 '확인 필요'로 두고, 열 매핑에서 올바른 항목으로 다시 확정하거나 그 시트를 계산에서 빼야 실행 |
| 검증 불가 | 구성 항목 열이 확정되지 않았거나(또는 여러 열), 비교할 수 있는 행이 없음 | 알림 없음 | 막지 않음 — "산식 검증 불가 — 이유 … (검증 완료 아님)"을 주의·대상에 남김 |

- **명시적으로 빼기:** 데이터 통계 분석은 대상 표의 '사용'을 끄면 그 시트를 `exclude`로 보내고, 결과의 '제외'(화면·Excel)에 "사용자가 계산에서 뺌"으로 남습니다. 묶기 통계 요약은 그 항목의 '포함'을 끄고 이유를 적을 수 있습니다(요약 시트 '뺌 (사용자)'). 시트 자체는 묶기 결과 파일에 그대로 들어갑니다.
- **다시 확정하기:** 예를 들어 통일부 '발신건수합계' 열만 '발신전체건수합계'로 확정하면 그 산식과 맞아 막히지 않습니다 (파일별 확정은 다른 부처의 매핑을 바꾸지 않음).
- 분석은 사용자가 확정한 매핑만 쓰므로, 구성 항목도 확정된 시트만 확인합니다. 판정 규칙 이름은 `analysis-policy-9`부터 이 정책입니다 (과거 결과는 그때 규칙 그대로).
- **묶기 통계 요약에서 합계와 구성 항목을 함께 고른 경우:** "같은 수량을 두 번 셉니다"라고 알립니다. 예: '발신건수합계'와 '발신Mail건수', 또는 '발신전체건수합계'와 '발신건수합계'. 항목마다 따로 계산하므로 결과 값은 같습니다.

## 3. 시연 자료 검산 (2026-10-22, 5개 부처 '사용량' 파일 — 임의로 만든 시연 자료)

원본 셀 수식과 값을 행마다 대조했습니다. 차이는 입력 오류가 아니라 산식 차이입니다.

| 부처 | 발신 합계 열 | 셀 수식 (2행) | 열 합계 | Mail+외부 | 차이 | 다른 행 |
|---|---|---|---:|---:|---:|---:|
| 행안부 | 발신건수합계 | `=E2+F2` | 52,726 | 52,726 | 0 | 0/50 |
| 기획예산처 | 발신건수합계 | `=E2+F2` | 20,155 | 20,155 | 0 | 0/50 |
| 재정경제부 | 총 발신 건수 | `=E2+F2` | 15,349 | 15,349 | 0 | 0/50 |
| 외교부 | 발신건수합계 | `=E2+F2` | 7,135 | 7,135 | 0 | 0/50 |
| 통일부 | 발신건수합계 | `=SUM(F2:I2)` | 25,945 | 23,260 | 2,685 | 50/50 |
| 전체 | | | 121,310 | 118,625 | 2,685 | |

- **통일부:** 발신건수합계 = 대용량파일전송발신수 + 시스템발신수 + 발신Mail건수 + 발신외부건수이며 50행 모두 맞습니다(시스템 2,001 + 대용량 684 = 2,685).
  - 같은 이름이라 자동 제안은 '발신건수합계'(Mail+외부)로 연결합니다.
  - 그대로 확정하면 다른 정의를 함께 더하게 됩니다. 통합 전 검사는 경고하고, 통계(분석·묶기 요약)는 다시 확정하거나 뺄 때까지 막습니다 (2장 표).
  - 그 파일만 '발신전체건수합계'로 확정하면 산식과 맞습니다.
- **재정경제부:** 대용량파일전송발신수 열(합 569)이 있지만 합계에는 넣지 않았습니다 — 부처마다 포함 범위가 다릅니다.
- **수신:** 다섯 부처 모두 수신건수합계 = 수신Mail건수 + 수신외부건수입니다.
- **업무 정의:** 어느 산식을 업무상 '발신 합계'로 볼지는 아직 정해지지 않았습니다. 정해지기 전에는 두 산식을 서로 다른 항목으로 따로 보입니다 (위 4번 결정 사항).
- **기간:** 날짜가 2026-10-01~21에 걸쳐 있고, 행이 일간 실적인지 월 누계인지 확정되지 않았습니다. 그래서 합계 85,740(발신Mail건수 250행)을 공식 10월 실적으로 표시하지 않습니다.

## 4. 조직 식별 (D-02)

- **대상 구분:** 분석·묶기 요약은 한 행이 무엇인지 기간·지역·기관코드·조직코드·조직명·담당부서 등으로 정합니다 (`analysis.IDENTITY_FIELDS`).
- **같은 이름, 다른 조직코드:** 조직코드를 '조직코드'로 확정하면 이름이 같아도 다른 조직입니다. 시연 통일부 '운영지원과' 1250370·680건과 1250663·400건은 반복이 아닌 두 대상입니다.
- **조직코드를 확정하지 않은 경우:** 시연처럼 '해당 없음'으로 두면 이름만으로 비교하므로 반복으로 보고 확인을 받습니다.
  - 이때 안내에 "이 시트에서 대상 구분에 쓰지 않은 열: '조직코드' 열 → '조직코드'"를 붙입니다.
  - 이름이 사전 항목과 정확히 같은 열만 짚고, 그 열을 자동으로 구분에 쓰지는 않습니다.
- **그대로 확인받는 것:**
  - 같은 조직코드가 같은 기간에 두 번 나오면 반복입니다 ('서로 다른 기록'을 고르기 전에는 계산하지 않음).
  - 다른 파일에 같은 대상이 있으면 파일 사이 중복으로 막습니다.
  - 코드가 빈 행은 나머지 구분 값(기관코드·조직명 등)으로 비교합니다.
- **'서로 다른 기록' 확인의 근거:** 결과 조건·Excel에 남깁니다. 예: "#5 시트1 (같은 대상 1개 2행 — 값 같음 0, 다름 1)"
- **시연 자료의 코드:**
  - 기관코드: 부처마다 7자리 하나 (행안부 1741000, 기획예산처 1052000, 재정경제부 1053000, 외교부 1262000, 통일부 1250000)
  - 조직코드: 7자리이며 부처 사이에 겹치지 않습니다. 엑셀 숫자 셀이라 선행 0이 없습니다.
- **글자 코드:** 선행 0이 있는 코드는 글자로 보존합니다 (PR #9 문자열 식별자 보존).

## 5. 결정이 필요한 사항 (지금 동작과 선택안)

| 사항 | 지금 동작 | 선택안 |
|---|---|---|
| 산식이 다른 합계를 함께 계산 | **정함 (2026-10-23):** 통합표·파일별 시트는 경고, 통계(분석·묶기 요약)는 다시 확정하거나 명시적으로 뺄 때까지 막음. 검증 불가는 막지 않고 표시 | — |
